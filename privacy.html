นโยบายความเป็นส่วนตัว — TypeFreeKub

ปรับปรุงล่าสุด: ตุลาคม 2026

สิ่งที่แอปทำ

TypeFreeKub อ่านการกดแป้นพิมพ์ในเครื่องของคุณเพื่อหาคำที่ถูกพิมพ์ด้วยแป้นไทย/อังกฤษผิดอัน แล้วพิมพ์คำที่ถูกต้องแทนให้ การทำงานทั้งหมดเกิดขึ้นในเครื่องของคุณ

สิทธิ์ที่ขอและเหตุผล

  • Input Monitoring — เพื่อเห็นการกดแป้นและรู้ว่าคำถูกพิมพ์ด้วยแป้นไหน
  • Accessibility — เพื่อตรวจว่าช่องข้อความไหนกำลังใช้งาน อ่านคำที่อยู่ติดกับ cursor เพื่อยืนยันก่อน/หลังแก้ และสลับแป้นพิมพ์

สิ่งที่แอปไม่ทำ

  • ไม่ส่งการกดแป้น ข้อความ หรือข้อมูลใด ๆ ออกจากเครื่อง ไม่มีเซิร์ฟเวอร์ของเรา ไม่มี analytics หรือ crash reporting
  • ไม่บันทึกสิ่งที่พิมพ์ลงดิสก์ แอปเก็บไว้ในหน่วยความจำเฉพาะคำปัจจุบัน (สูงสุด 128 ตัวอักษร) และล้างทันทีเมื่อเว้นวรรค คลิก หรือเปลี่ยนหน้าต่าง
  • ไม่ทำงานในช่องรหัสผ่าน (secure text field) และเมื่อระบบเปิด Secure Input เช่นใน Terminal หรือหน้าต่างใส่รหัสผ่านของ macOS
  • ไม่อ่านเนื้อหาเอกสารทั้งหมด อ่านเฉพาะช่วงสั้น ๆ ก่อน cursor (ไม่เกิน 256 ตัวอักษร) เพื่อยืนยันการแก้

ข้อมูลที่เก็บในเครื่อง

  • การตั้งค่าของแอป (เปิด/ปิดฟีเจอร์, แป้นอังกฤษที่เลือก, ภาษา)
  • รายการ "ไม่แก้คำเหล่านี้": คำที่คุณกด ⌃⌘Z ย้อนกลับเอง เป็นข้อความเดียวที่แอปบันทึก และคุณลบได้จากเมนูทุกเมื่อ
  • บันทึกวินิจฉัยในระบบ log ของ macOS ประกอบด้วยเหตุผลและตัวเลขเท่านั้น (เช่น ความยาวคำ ความมั่นใจ) ไม่มีข้อความที่พิมพ์

การเชื่อมต่ออินเทอร์เน็ต

การเชื่อมต่อเดียวของแอปคือการตรวจสอบเวอร์ชันใหม่ผ่าน Sparkle (ดาวน์โหลดไฟล์ appcast.xml จากเว็บไซต์ของเรา) วันละครั้ง ซึ่งส่งเฉพาะข้อมูลมาตรฐานของ HTTP request และเวอร์ชันแอป คุณเลือกเองว่าจะติดตั้งอัปเดตหรือไม่
